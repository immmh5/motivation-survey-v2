# مقياس الدافعية للتعلم

## الصفحات
- `/` صفحة الطالب (المقياس).
- `/admin` لوحة التقارير (تطلب اسم مستخدم وكلمة مرور).

## الرفع على Render
1. ارفع هذا المجلد على GitHub.
2. في Render: New > Web Service > اختر المستودع.
3. Build Command: `npm install`  —  Start Command: `npm start`
4. في Environment أضف:
   - `ADMIN_USER` = اسم المستخدم للوحة
   - `ADMIN_PASSWORD` = كلمة مرور قوية
5. مهم جدًا: الخطة المجانية تمسح الملفات عند إعادة التشغيل. لحفظ الحلول دائمًا:
   أضف Disk (من إعدادات الخدمة > Disks) بمسار مثل `/var/data`،
   ثم أضف متغير `DATA_DIR` = `/var/data`.
   وإن بقيت على المجانية، حمّل ملف ZIP من اللوحة باستمرار.

## أين تُحفظ الحلول
كل طالب في ملف JSON مستقل داخل `data/submissions/`.

## تقرير المعلم
من اللوحة اضغط الزر الأخضر «تقرير المعلم» أو افتح `/admin/report`.
اكتب اسم المدرسة والمعلم واسمك في الغلاف، ثم اختر: تحميل PDF، طباعة، صور الصفحات (ZIP)، صور الرسوم (ZIP)، أو ملف يفتح بدون إنترنت.

## الإرسال من أي جهاز
- الطالب لازم يفتح المقياس من رابط الموقع (مو من ملف محفوظ في الجهاز).
- إذا كان الخادم نايم أو النت ضعيف، الصفحة تعيد المحاولة تلقائيًا وتحفظ الإجابات في الجهاز وترسلها لما يرجع الاتصال.
- إعادة المحاولة ما تكرر الحل في البيانات.
- نصيحة: افتح رابط الموقع بنفسك قبل الحصة بدقيقة عشان يصحى الخادم.

## التنزيلات من اللوحة
ZIP شامل، JSON لكل الحلول، CSV يفتح في Excel، تقرير إحصاءات، JSON لكل طالب، صور PNG لكل رسم، وطباعة PDF.

## التشغيل محليًا
`npm start` ثم افتح http://localhost:3000
